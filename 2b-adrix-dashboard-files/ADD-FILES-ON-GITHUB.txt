2B-ADRIX PROFILE DASHBOARD — GITHUB.COM SETUP

Add these two source files to the main branch:

1. profile_dashboard.py
   Location: repository root (same level as README.md)

2. update-profile-dashboard.yml
   Location: .github/workflows/update-profile-dashboard.yml

Then copy README-dashboard-section.html into README.md where you want the statistics area.

The six SVG files in output/ below are PREVIEW PLACEHOLDERS only. You do not need to upload them manually. The GitHub Actions workflow creates and publishes the real SVGs to the output branch after a successful run.

Keep your existing .github/workflows/snake.yml. The dashboard workflow adds/updates its own six SVGs in the output branch and does not force-replace that branch.

GitHub settings:
Settings -> Actions -> General -> Workflow permissions -> Read and write permissions.

Then run:
Actions -> Update Profile Dashboard -> Run workflow.

Create a GitHub classic Personal Access Token with read:user and public_repo scopes. In this repository, go to Settings -> Secrets and variables -> Actions -> New repository secret. Name it PROFILE_TOKEN and paste the token as its value. The workflow uses this token only to read account/contribution data; github.token is used to publish files. Never paste the token into README, source files, or chat.
