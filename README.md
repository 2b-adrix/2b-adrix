## 👋 About Me

I'm **Aditya Mishra**, a 3rd-year **B.Tech Computer Science Engineering** student focused on **Native Android Development**.

I enjoy building applications from the ground up — from polished Android interfaces and clean architecture to APIs, databases, authentication, and cloud-backed systems.

My main engineering focus is:

```text
Native Android
      ↓
Kotlin + Jetpack Compose
      ↓
Clean Architecture + Modern Android
      ↓
REST APIs + Spring Boot
      ↓
Database + Cloud + Scalable Systems
```

* 📱 Focused on **Native Android Engineering**
* 🧠 Building with **Kotlin + Jetpack Compose**

* 🔐 Interested in **application security & secure engineering**
* 🧩 Learning **DSA, System Design & scalable software architecture**
* 🚀 Building projects that solve practical problems
* 🤝 Open to collaboration, internships, hackathons & interesting engineering challenges
